# Operations Proposals

이 디렉토리는 아직 채택·구현되지 않은 운영 자동화 제안을 보존한다. 이 문서는
현재 운영 runbook이나 보안 기준이 아니다. 채택된 결정은 `architecture/`, `security/`,
`deployment/`의 해당 정본으로 승격하고, 원본 제안은 Historical/Derived로 남긴다.
